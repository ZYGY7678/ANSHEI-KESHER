# עסקים וטלפונים בישראל — Android 4.4.4

אפליקציית ספר טלפונים לעסקים, חנויות ומרכזים בישראל, ללא מספרים פרטיים.

## מה יש בגרסה הראשונה
- מינימום Android 4.4.4 / API 19
- חיפוש לפי שם עסק, עיר, כתובת, קטגוריה או מספר
- סינון לפי קטגוריות
- לחיצה על עסק מחייגת למספר הציבורי שלו
- ממשק RTL בעברית
- עבודה עם מקשים פיזיים דרך פוקוס ברירת המחדל של Android
- טעינת מאגר ציבורי ועדכני בזמן ההפעלה
- שמירה על קוד ללא AndroidX וללא ספריות מודרניות כבדות

## מקור נתונים
הגרסה משתמשת במאגר הציבורי של משרד התיירות **"עסקים במסגרת החזר מעמ לתייר"**, שמציג 3,678 רשומות וכולל שם, כתובת, עיר, טלפון וקטגוריה. המאגר מתעדכן בפורטל data.gov.il.

חשוב: זהו מקור ציבורי אחד ולא "כל העסק בישראל". כדי להגיע לכיסוי רחב יותר, הארכיטקטורה מאפשרת להוסיף מקורות ציבוריים נוספים, למשל מאגרי רישוי עסקים עירוניים ונתוני OpenStreetMap, תוך שמירה על מספרים עסקיים/ציבוריים בלבד.

## בנייה
הפרויקט משתמש ב-Android Gradle Plugin 4.2.2, Gradle 6.7.1, compileSdk 28 ו-minSdk 19.
GitHub Actions מבצע build אוטומטי בכל push לענף `android-business-directory`.

## הערה על פרטיות וזכויות
האפליקציה מיועדת למספרי קשר של עסקים ושירותים ציבוריים בלבד. אין להוסיף מספרים פרטיים או מידע אישי שאינו מיועד לפרסום.


Build note: fallback business list is shown immediately for Android 4.4.4 compatibility.
